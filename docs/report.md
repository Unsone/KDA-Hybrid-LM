# 技术报告框架与当前证据

状态日期：2026-11-16。此文件是逐步填写的报告，不是已完成的实验论文。

## 摘要草案

本项目实现了标准因果自注意力和四种矩阵记忆 Mixer，提供统一接口，并实现 RMSNorm、SwiGLU、RoPE 与因果短卷积。当前完成的是组件级正确性验证，尚无端到端训练与性能结论。后续计划在 MQAR 和小型混合语言模型上比较记忆能力、门控粒度、质量与推理成本。

## 1. 问题与范围

研究固定状态记忆的容量和干扰，以及线性/全注意力层混合的取舍。属于已有算法的独立实现与实验研究，不宣称提出 DeltaNet/GDN/KDA。本项目当前简化门控与论文完整模型不同。

## 2. 方法

计算公式与状态方向见 [math.md](math.md)，结构、接口与实现边界见 [architecture.md](architecture.md)。最终报告应列出每个配置的真实参数量、层布局、位置编码、卷积、归一化、输出门控和 Dropout。

## 3. 已有验证

本机 Python 3.11.15 / PyTorch 2.15.0+cpu 于上述日期执行 `python -m pytest tests -q`，收集并通过 21 项测试：Mixer 10 项，RMSNorm 3 项，其余 modules 8 项。

| 覆盖 | 证据 |
|---|---|
| 递推 Mixer | 因果性、分段/逐 token 状态传递、输入与参数梯度、输出 Dropout |
| 数学规则 | 线性版与显式因果矩阵计算一致；GDN/KDA 与状态转移矩阵一致 |
| 门控退化 | KDA 各通道门相同时与 GDN 一致 |
| SoftmaxAttention | PyTorch SDPA 对拍、缓存、因果性、梯度、注意力 Dropout |
| RMSNorm | PyTorch 输出/梯度对拍、零输入、FP16/BF16 输入 |
| SwiGLU | 逐 token 独立性、梯度、Dropout |
| RoPE | 二维旋转、范数、相对位置/offset、分段、低精度 |
| 短卷积 | 手算、因果性、梯度、分段缓存和 K=1 |

重构基类前后另做过相同权重的输出、状态和梯度对比；它属于开发验证记录，不是性能实验。测试数会随后续开发变化，应按实际命令更新。

## 5. 局限与失败分析

当前只有基础 PyTorch 实现；无正式训练收敛证据，无 GPU 训练或内核测试，无完整论文门控结构。RoPE/短卷积仍未集成。AMP 下递推乘法的精度策略需处理；固定状态存在信息干扰，混合网络仍保留增长的 KV。记录负结果、失败种子、优化困难与训练中断，不能只选择最好结果。
